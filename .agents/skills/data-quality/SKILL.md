# Data Quality & Safety Skill

## Purpose
Validates all AI and external API data against strict JSON schemas, verifies evidence links, checks consistency, and flags or rejects ungrounded outputs.

## Rules
- Enforce strict JSON schema validation.
- Reject ungrounded claims and impossible scores.
- Flag low-confidence conclusions for human review.
