# Website Audit Skill

## Purpose
Inspects public web presence for SSL, responsive viewport, SEO basics, meta tags, and interactive conversion capabilities (booking, ordering, WhatsApp, e-commerce).

## Rules
- Only inspect publicly accessible endpoints.
- Never perform vulnerability scanning or intrusive security penetration.
- Produce evidence-backed qualitative analysis with a 0–100 score.
